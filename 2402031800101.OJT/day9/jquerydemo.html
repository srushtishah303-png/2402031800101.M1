FAQs

1. What is jQuery?

jQuery is a fast and lightweight JavaScript library that simplifies HTML document manipulation, event handling, and animations.

2. How do I hide an element using jQuery?

You can use the hide() method. Example: $("#para1").hide();

3. How do I show an element using jQuery?

You can use the show() method. Example: $("#para1").show();

4. What does fadeOut() do?

The fadeOut() method gradually hides an element by reducing its opacity.

5. What does $(document).ready() do?

It ensures that the code runs only after the entire HTML document has been loaded.
